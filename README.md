# ФинПрактика · тренажёр финансов и оценки проектов

**ФинПрактика** — бесплатное веб-приложение для регулярной практики по финансовой отчётности, налогам, финансовому моделированию и оценке проектов. Задачи меняются при каждой генерации, ответы проверяются автоматически, а разбор объясняет решение.

[**Открыть приложение**](https://kuznetzdev.github.io/finances_and_projects/) · [Каталог знаний](docs/CURRICULUM.md) · [Архитектура](docs/ARCHITECTURE.md) · [Дизайн-система](docs/DESIGN_SYSTEM.md)

> **Статус:** версия 3.0.0. Финансовые и налоговые примеры предназначены для обучения, не для бухгалтерских решений. Приложение не является официальным ресурсом МФТИ.

## Что умеет

| Раздел | Содержание |
| --- | --- |
| **Задачи** | 55 генераторов, 9 тематических блоков, 4 уровня сложности, новые параметры по кнопке |
| **Расчёты** | PV, FV, YTM, WACC, NPV, CFO, амортизация, налоги, финансовые коэффициенты |
| **Финансовая логика** | P&L / Cash Flow / Balance Sheet, метод начисления, оборотный капитал, классификация денежных потоков |
| **Тесты** | Вопросы с одним или несколькими ответами, распознавание операций и терминов |
| **Карточки** | 46 понятий и 20 ситуаций, самопроверка «знаю / повторить» |
| **Словарь** | Ликвидность, оборачиваемость, рентабельность, стоимость капитала и другие определения |
| **Прогресс** | История ответов и статистика в памяти браузера |

Работает с телефона и компьютера, без регистрации и сервера. Поддерживаются светлая и тёмная темы.

## Быстрый запуск

**Онлайн:** открой [ФинПрактику](https://kuznetzdev.github.io/finances_and_projects/) после успешной первой публикации в GitHub Pages.

**Локально** (нужны Python 3 и Node.js 22+ только для тестов):

```bash
git clone https://github.com/kuznetzdev/finances_and_projects.git
cd finances_and_projects

# Проверка генераторов
npm test

# Запуск статического сайта
python3 -m http.server 8000 -d site
```

Открой http://localhost:8000/. Для самого сайта установка зависимостей не требуется. Не открывай `site/index.html` через `file://`: ES-модули браузер может заблокировать.

## Развёртывание в GitHub Pages

Репозиторий уже содержит `.github/workflows/pages.yml`. Workflow запускается при каждом push в `main`, проверяет генераторы командой `npm test` и публикует папку `site/`.

Для первого включения в GitHub:
1. `Settings → Pages`.
2. В разделе `Build and deployment` выбери **GitHub Actions**.
3. Открой вкладку **Actions** и убедись, что workflow **Test and deploy to GitHub Pages** завершился успешно.
4. Ссылка на тренажёр: **https://kuznetzdev.github.io/finances_and_projects/**.

Хостинг публичного репозитория не требует платной серверной инфраструктуры.

## Структура проекта

```text
.github/workflows/pages.yml   # тесты и публикация
site/
  index.html                  # приложение
  styles.css                  # адаптивный дизайн
  app.js                      # интерфейс и локальное состояние
  engine/
    index.js                  # реестр и проверка ответов
    helpers.js                # утилиты
    legacy.js                 # исходные проверенные генераторы
    templates/                # независимые семейства новых генераторов
  data/
    knowledge.js              # определения, карточки и вопросы
    tax.js                    # налоговые политики с привязкой к году
tests/                        # автоматические проверки и регрессии
docs/                         # архитектура, дизайн, учебные источники, политика налогов
```

## Как добавить контент

- **Генератор:** создай модуль в `site/engine/templates/` и зарегистрируй его в `site/engine/index.js`. Соглашения и пример: [ARCHITECTURE.md](docs/ARCHITECTURE.md).
- **Термин:** добавь запись в `site/data/knowledge.js`. Она используется в словаре, карточках и тестах.
- **Налоговое правило:** добавь версию политики с годом и источником в `site/data/tax.js`. **Общая ставка налога на прибыль РФ — 25% в 2026 году.** Для исторических задач ставка определяется условием.
- **Новый формат ответа:** реализуй проверку в ядре и компонент ввода в `site/app.js`.

Подробности: [архитектура](docs/ARCHITECTURE.md), [учебная карта](docs/CURRICULUM.md), [налоговые допущения](docs/TAX_POLICY.md), [требования к дизайну](docs/DESIGN_SYSTEM.md), [контроль качества](docs/QUALITY.md), [расширенное ТЗ](docs/SPECIFICATION_2.0.md).

## Достоверность и ограничения

- Генераторы работают детерминированно, чтобы одна и та же задача воспроизводилась и проверялась одинаково.
- Пользовательский прогресс хранится в `localStorage` на конкретном устройстве. Очистка данных браузера удаляет прогресс.
- В публичном репозитории **нет исходных PDF лекций**: права на их распространение должны быть согласованы отдельно.
- Налоги в учебных примерах упрощены; нормы и ставки привязаны к версии справочника.
- Полноценная многолетняя связанная финансовая модель, интервальное повторение, общий рейтинг и синхронизация устройств остаются в плане развития.

## Разработка и вклад

Изменения лучше добавлять небольшими независимыми модулями с тестами. Для нового генератора проверь корректность финансовых уравнений, пограничные значения и детерминированность по seed. Перед отправкой изменений запускай `npm test`.
