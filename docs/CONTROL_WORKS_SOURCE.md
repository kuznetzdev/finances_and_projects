# Контрольные работы: источник и правила интеграции

Источник: девять фотографий бумажных контрольных, предоставленных пользователем в чате 29.10.2026. Из фотографий перенесены условия и числовые данные; текст решений написан отдельно, без слепого копирования рукописных ответов. Фотографии и персональные рукописные данные в Git не загружаются.

## Работа №1, вариант «Альфа»

- CW-F01: метод начисления, P&L, Balance Sheet и CFS.
- CW-F02: косвенный метод построения CFO.
- CW-F03: три формы отчётности за январь: взнос 1000, кредит 500, оборудование 600, услуги 800/600/200, зарплата 300/250/50, амортизация 50, погашение кредита 100 (тыс. ₽).
- CW-F04: анализ 2025/2026: выручка 5000/6500, прибыль 400/700, дебиторка 600/1300, запасы 500/900, кредиторка 700/1000, ОС 1500/2000, кредиты 1000/1500, деньги 800/450.

## Работа №1, вариант «Технолюкс»

- CW-F05: назначение трёх форм отчётности.
- CW-F06: P&L: выручка 20, себестоимость 9, административная зарплата 2, реклама 1,5, аренда 1, проценты 0,5 млн ₽; налог 25%.
- CW-F07: продажа в два раза больше по прежней цене, аванс 300 тыс. ₽ за следующий месяц, погашение половины кредита. Принята фиксированность прочих расходов и текущих процентов; для суммы погашения кредитная база неизвестна.

## Правила проверки

1. Сначала сохранить исходные числа и содержание вопроса, затем дать независимо просчитанное решение.
2. Не превращать неизвестные платежи, проценты или остатки в фиктивные исходные данные.
3. Числовые ответы выводить в автоматическую проверку **только при однозначном результате либо явно объявленной учебной модели**. Остальные вопросы оставлять для самопроверки.
4. Не смешивать начисление расходов с их оплатой; не считать погашение тела кредита расходом P&L; амортизацию не вычитать дважды.
5. В CW-F04 нельзя восстановить точный CFO, CFI, CFF только из двух балансов. В CW-F08 и CW-F13 точный CFO без данных об оборотном капитале и выплатах также не определяется.
6. Для CW-F07 аванс будущего месяца и погашение тела кредита не увеличивают и не уменьшают текущий P&L соответственно. Рост себестоимости пропорционально количеству товара — **отдельное допущение**.
7. Контроль CW-F11 применяет учебную классификацию процентов в CFO. Другие применимые стандарты или политики классификации нужно обозначать отдельно.
