# Разделённый математический аудит банка задач

**Цель:** независимо проверить все числовые решения фиксированного банка и классифицировать генераторы по уровню математической проверки, не выдавая структурные тесты за финансовую экспертизу.

**База:** PR #30, ветка `audit/all-cases-exam-oracles-2026-11`.

## Рабочие блоки

- [ ] Банк-источник: 54 числовых вопроса из 21 исходного кейса F/T/V. Независимые формулы, меры против незаявленных допущений.
- [ ] Лекции и тематические наборы: внести остальные фиксированные числовые ответы в независимые финансовые эталоны по темам (LBO, VC, капитал, инструменты, DCF, налоги).
- [ ] Объединить независимые проверки: 310/310 контрольных ответов, строгий контроль отсутствующих/лишних ответов и единиц, внедрение в блокирующий preflight.
- [ ] Проверить покрытия 126 генераторов отдельно: независимые оракулы, частичные числовые тесты, непокрытые математические ответы. Непроверенные ответы маркировать как непроверенные, не как корректные.
- [ ] Прогнать модульные, генераторные, браузерные и мобильные тесты в CI. Записать фактические результаты и ограничения.

**Критерии:** ни один числовой эталон не копируется из `CASE_CHECKPOINTS`, исходные числа закреплены в отдельном модуле, каждая умышленная подмена вычисленного ответа выявляется тестом. Итоговый отчёт отличает полную независимую проверку от проверки формы/интерфейса.
