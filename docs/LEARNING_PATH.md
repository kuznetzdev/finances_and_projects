# Учебный маршрут и форматы тренировки

## Вход

Новому пользователю достаточно открыть «Задачи». По умолчанию включены «Вся программа» и «Все темы», уровень «Разминка». Выбор конкретного направления показывает только задания по соответствующим навыкам; при невозможности найти задания на текущем уровне приложение повышает сложность до первого доступного уровня. Чтобы вернуться к полной смеси, выберите «Вся программа».

## Три вида тренировки

**1. Быстрая проверка понятий.** Карточка → переворот → проверка определения → отметка «Уже знаю» либо следующая карточка. Вопросы перемешаны. Отметка не удаляет понятие из общей колоды.

**2. Распознавание операций.** Быстрый тест → выбор одного из четырёх ответов → пояснение, почему так → следующий вопрос. Варианты ответов перемешаны, когда возможно подбираются из близких семейств понятий. Недавние события и термины исключаются из повторной выборки.

**3. Расчёты.** Короткая задача → ответ(ы) → проверка → подробное объяснение. Для комплексного кейса: последовательно ответить на шаги или показать все этапы сразу; далее проверить результаты по каждому пункту. Ответы не стираются при переходах.

## По сложности

- **Разминка:** один-два прямых расчёта или классификация.
- **Практика:** несколько взаимосвязанных вычислений с дополнительными параметрами.
- **Экзамен:** сравнение альтернатив, учёт сроков, знаков и зависимостей.
- **Эксперт:** DCF с терминальной стоимостью, полная декомпозиция Дюпона, LBO, реальные опционы, трёхформенная финансовая модель, стресс-сценарии.

Не каждый шаблон используется на каждом уровне. Уровень — фильтр по минимальной сложности генератора. Это сознательно сохраняет возможность закрепления базовых задач даже в сложном режиме, а не меняет произвольно их математический смысл.

## Темы и границы покрытия

Подробная тематическая матрица: [CURRICULUM.md](CURRICULUM.md). Реализованы отдельные расчёты по цене облигаций, НКД, дюрации, CAPM, beta, EAC, DPP, DCF, мультипликаторам, NAV, грантовому элементу, pre/post-money, LBO и Red Team. Часть тем пока представлена только карточками: LLCR, book building, «футбольное поле» оценок. Амортизируемые облигации теперь представлены также генератором и разобранным кейсом банка. Моделирование социальных проектов представлено формулой Рамсея; оценка военных проектов, детальный разбор Colt Defense и полный редактор пользовательской финансовой модели пока не реализованы.

## Важный принцип для авторов заданий

Задача всегда фиксирует допущения: в какой валюте и масштабе указаны суммы, включён ли НДС, когда поступает денежный поток, что происходит с долгом, какие ставки налогов используются, есть ли другие операции. Генерация не должна создавать отрицательные величины там, где они не имеют экономического смысла. Отрицательный CFO, NPV и EBITDA допустимы, если они логически объясняются исходными данными.


## Практика по исправленному банку

Для отработки конкретных методических примеров в режиме «Банк задач» выбирайте одну из 57 исходных задач. Числовые контрольные точки проверяются автоматически только в 21 однозначном кейсе. Остальные задания предназначены для записи собственного хода решения и сравнения с развёрнутым ответом. При необходимости отмечайте задачу на повторение, а у сложных условий сначала формулируйте допущения.
