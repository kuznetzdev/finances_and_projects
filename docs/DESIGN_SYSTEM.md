# Дизайн-система и требования к UX

## Цель

Учебное приложение для 10-минутных тренировок в дороге и продолжительных занятий за компьютером. Главный критерий — задача читается, ответ удобно вводится, ошибки понятны и следующий вопрос достигается за одно действие.

## Визуальное направление

**Financial editorial workspace**: лаконичный интерфейс финансового блокнота. Спокойный фон, выразительная типографика для заданий, глубокий зелёный для активных областей, точечный терракотовый акцент, никаких декоративных градиентов, одинаковых карточек-сувениров или бессмысленных графиков. Эстетика функциональная, а не презентационная. Дизайн опирается на идеи product-mode Impeccable, визуальную экономию и контрастную иерархию, описанные в обзоре Composio.

### Токены

- Фон `#f6f7f2`, бумага `#ffffff`, основной текст `#192e2d`.
- Глубокий зелёный `#163f3c`, акцент `#e07857`, выделение `#d4ef9c`.
- Слабые разделители `#e1e7dd`, скругления 11–22 px.
- Заголовки: Georgia (хорошо читает кириллицу), основной интерфейс: Avenir Next / Segoe UI / системный без загрузки внешних шрифтов.
- Допускается тёмная тема, состояние хранится локально. Цвет состояния никогда не является единственным носителем информации.

### Сетка и адаптивность

| Экран | Композиция |
|---|---|
| ≥ 1220 px | левое меню 264 px, большой лист задания, компактная колонка прогресса |
| 1050–1219 px | узкое боковое меню, содержимое адаптивно |
| 781–1049 px | одна колонка задачи, контекстные метрики ниже |
| ≤ 780 px | верхняя строка бренда, нижняя навигация из пяти действий |
| ≤ 520 px | компактные отступы, одна колонка вариантов, горизонтально прокручиваемые тематические фильтры |
| 320 px | все ключевые функции доступны без горизонтальной прокрутки страницы |

### Контроль UX

1. Пользователь сразу видит выбор темы, сложности и условие текущей задачи.
2. Данные условии и ответы находятся на одном экране по вертикали без модальных окон.
3. Числовые ответы используют `inputmode="decimal"`, значок единицы расположен рядом, поддерживаются `12,5` и `12.5`.
4. Есть кнопка проверки. После проверки подсвечивается каждая ошибка и показывается точный правильный ответ.
5. Объяснение открывается по запросу, но не скрывается за платным доступом.
6. Ошибки сохраняются локально, задачи по одной и той же ссылке воспроизводимы.
7. Для многовариантных ответов используются чекбоксы, не drag-and-drop.
8. Квиз поддерживает последовательные ответы и немедленное объяснение.
9. Карточка переворачивается кнопкой, управление не требует жестов.
10. Поиск словаря сразу фильтрует термины, нет регистрации, рекламы и отвлекающих баннеров.

### Доступность

- Цели нажатия не менее 44 px по высоте для главных действий.
- Видимый `:focus-visible` и семантические `button`, `fieldset`, `legend`, `label`.
- Порядок клавиатурного обхода соответствует смысловому порядку.
- Статус проверок сопровождается текстом, не одним цветом.
- Поддержка `prefers-reduced-motion`.
- Никаких зависимостей от внешних CDN-шрифтов.
- Контраст основной типографики рассчитан с запасом, вспомогательные серые значения темнее декоративных.

### Границы качества

Рекомендации Impeccable и GPT Taste использованы как вдохновение, но отдельные внешние пакеты этих навыков не установлены и не исполнялись как код. Для визуального подтверждения нужен браузер без административной блокировки открытия локальных страниц; фактический статус такой проверки описан в QUALITY.md.

## Уточнения для длинного контента (v4)

1. **Карточки не обрезаются.** Высота `.flip-surface` задаётся содержимым; нет жёстко заданной высоты или скрывающего `overflow: hidden`. Сложные термины и подробные определения переносятся по словам. Контраст понятия всегда виден вместе с определением.
2. **Случайный порядок карточек.** В режиме всех категорий и при выборе конкретной категории колода перемешивается. Переходы «назад» и «следующая» сохраняют последовательность текущей колоды, новая формируется после завершения.
3. **Большие финансовые кейсы.** Начиная с четырёх ответов показывается прогресс «Этап 1 из N», переходы «Назад» и «Далее» и переключатель просмотра всех этапов. Поля остаются в документе, а значит, введённые значения при переходе не теряются.
4. **Мобильные экраны.** Основной флоу не требует drag-and-drop, не скрывает определения по высоте и не вынуждает прокручивать широкие таблицы. Для карточек используется три компактных действия в одну строку; основные кнопки имеют доступные размеры.
5. **Тексты в интерфейсе.** Разделы называются функционально: «Финансовые задачи», «Быстрые тесты», «Карточки терминов», «Финансовый словарь», «Мой прогресс». Убраны рекламные слоганы, шутки и отвлекающие формулировки.

## Компактная навигация и закреплённые действия (v6)

1. Цвет эмблемы задан независимо от светлой/тёмной темы (`#d9f19f` на `#153c3b`), так как боковое меню остаётся тёмным в обеих темах.
2. Основные действия находятся в отдельном `site/interaction.css`. Используется `position: sticky`, а не постоянная плавающая кнопка, чтобы панель не закрывала рабочую область вне задания.
3. Квиз: до ответа отображается «Пропустить», после ответа «Следующий вопрос». Переход к новому вопросу возвращает фокус к его тексту. Пропуск не входит в знаменатель точности.
4. Генератор: подсказка и копирование ссылки остаются вторичными действиями; проверка, переход между этапами и пропуск собраны в одной панели.
5. Банк задач: аналогичная компактная панель навигации; ранее введённые ответы и заметки сохраняются при пропуске.
6. Карточки понятий: кнопки «Назад» / «Уже знаю» / «Следующая» закрепляются в пределах карточки при длинных определениях.
7. На телефоне закреплённая панель располагается **выше** нижней навигации с учётом `env(safe-area-inset-bottom)`; на коротком ноутбуке снижены вертикальные отступы и размер крупных заголовков.
8. Контроль: если активная область имеет очень длинное условие или объяснение, оно остаётся прокручиваемым; основное действие не исчезает за пределами экрана.

## Переключение генератора и банка (v7)

- Общий переключатель из двух вкладок помещается непосредственно под заголовком учебного раздела; структура экранов не меняется.
- `position: sticky; top: 12px` сохраняет доступ к режимам при прокрутке длинных кейсов. На небольшом экране отступ сокращается до 7 px.
- Текст активного режима контрастен для обеих тем: фоновый `--forest`, текстовый `--bg`; неактивный получает мягкое выделение при наведении.
- Минимальная высота управляющей кнопки 44 px; обе кнопки делят доступную ширину без горизонтального скролла.
- Возврат в генератор работает после любой перерисовки банка за счёт делегирования кликов с постоянного контейнера.
- Браузерная визуальная приёмка отмечена отдельно: административная блокировка Chromium исключила фактическое получение скриншотов обновлённой версии.
