# Интерфейс ФинПрактики: рабочая структура

Обновлено: 29 октября 2026 года.

## Зачем изменили

ФинПрактика — инструмент для решения финансовых задач, работы с парадоксами, проверки знаний и поиска определений. Экран должен помогать найти задание, прочесть условие, ввести ответ, получить обратную связь и продолжить обучение. Декор без такой функции не нужен.

| Сценарий | Основное действие | Сопутствующая информация |
| --- | --- | --- |
| Генератор | Проверить решение | Фильтры, подсказка, смена задачи, история результата |
| Банк задач | Выполнить текущий этап | Условие, критерии, эталонный разбор после попытки |
| Тесты | Выбрать один вариант | Текст вопроса, подсказка, ответ с объяснением |
| Парадоксы | Сформулировать собственный вывод | Допущения, разбор, самопроверка |
| Словарь | Найти нужный термин | Определение, формула, применимость |
| Прогресс | Определить, что повторить | Статистика только по совершённым действиям |

## Принятые решения

1. Заголовки разделов стали компактнее: удалены декоративные индексы «01–06» и дубль названия раздела перед рабочей областью.
2. Условие текущей задачи оформлено как **главный контент**, с явными блоками «Условие» и «Ваше решение». Панель подбора задачи остаётся непосредственно перед заданием.
3. Не создаём карточку на каждый термин, парадокс или ответ теста. Повторяемые единицы представлены строками с общей направляющей и разделителями.
4. Статистика решения располагается в одной боковой сводке и не конкурирует с формой. Пока ответов нет, точность обозначена как **«Нет данных»**, а не «0%».
5. Убрано утверждение об актуальности всех материалов на 2026 год: условные ставки в учебных примерах не являются подтверждением применимости каждого показателя к текущей дате.
6. Цвет выделяет активное действие, правильный или ошибочный результат. Контраст и слова должны работать вместе: оценки не передаются одним цветом.
7. Оставлены функциональные панели: фильтры, условия задачи, разбор формулы и источник. Для этих сущностей рамки полезны, а не декоративны.
8. Добавлена клавиатурная ссылка «К содержанию», видимый фокус для полей и кнопок и перенос фокуса на заголовок нового раздела.
9. На узком экране сохраняется нижняя навигация, корректная область прокрутки формул и кнопка новой случайной задачи. При сокращении ширины словарь переходит на одну колонку.
10. Варианты теста после ответа остаются читаемыми, хотя сами кнопки недоступны для повторного выбора.

## Ограничения проверки

Нет сетевых загрузок во время обычного просмотра: приложение статическое, рабочий контент загружается вместе с модулем. Для поиска без результата есть отдельное пустое состояние. Ошибки в генераторе и недоступные типы задач должны обрабатываться отдельно логикой приложения, а не имитироваться «скелетонами».

Оценка качества интерфейса опирается на проверки в `scripts/smoke-visual.mjs` и автоматические тесты. Это контроль функциональности, не замена исследованию поведения пользователей. Реальная точность финансовых формул и данных проверяется существующим финансовым preflight, а не визуальным тестированием.
