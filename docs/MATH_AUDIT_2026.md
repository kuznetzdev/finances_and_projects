# Независимая проверка финансовой математики

Редакция: 03.11.2026. Проверяемый код: PR #30 (ветка `audit/all-cases-exam-oracles-2026-11`).

## Что означает «проверено»

**Фиксированные задачи:** каждое числовое поле пересчитывается независимой функцией из параметров оригинального условия. Формулы находятся в `scripts/lib/*-oracles.js` и не импортируют ответы из `site/data/*-checkpoints.js`. Контроль блокирует сборку при изменении ответа, единиц измерения, состава полей или наличии новых неописанных чисел.

**Генераторы:** эти проверки независимы от фиксированного банка. Статусы ниже отражают реальное качество автоматической проверки; структурный тест не доказывает правильность финансовой формулы.

Остальные 48 фиксированных задач имеют только текстовые пояснения и обсуждения, которым автоматическая проверка числового ответа не применяется. Их источники, содержание и открытие решения проверяются в браузере; отдельная предметная экспертиза каждого утверждения остаётся самостоятельной задачей.

Тест `tests/all-fixed-independent-math.test.js` намеренно изменяет **каждое из 310 чисел** и **каждую единицу измерения**. Проверка должна показать ошибку независимо от того, принимает ли приложение собственное сохранённое значение. Округлённые значения исходного банка сравниваются с результатом округления до 0,01, за исключением явно указанной 4-знаковой дюрации.

### Найденная и исправленная ошибка генератора DCF

В `a-dcf-ev` ранее использовалось `EV = PV(прогнозных FCFF) + TV₃`, где `TV₃` является стоимостью **на конец года 3**, а не на сегодня. Исправлено на:

```
EV = PV(FCFF1, FCFF2, FCFF3) + TV3 / (1 + WACC)^3
Equity = EV - Debt + Cash
```

Генератор получил отдельный независимый oracle `scripts/lib/advanced-dcf-oracle.js` с пересчётом по параметрам, видимым студенту. Тест `tests/advanced-dcf-ev-independent.test.js` воспроизвёл старую ошибку до исправления.

## Принцип честной постановки

Для задач с недостаточными входными данными сохраняются разные сценарии и явно написанные допущения. В 13 задачах к контрольной это особенно относится к PREP26-02, PREP26-03, PREP26-08, PREP26-10, PREP26-11, PREP26-12 и PREP26-13.

**T11:** заголовок оригинального источника уже сообщает, что облигация бескупонная. Теперь это также повторено в самом условии, чтобы карточка была самостоятельной без заголовка. Число 857,34 ₽ от этого не меняется.

**PREP26-11:** 52% падения EBIT — порог **нулевой прибыли** при 80% долга и A=5 000; Kd=ROA — отдельный порог **знака эффекта финансового рычага**. Смешивать их нельзя.

## Воспроизводимый контроль

```bash
npm test
npm run preflight
node scripts/audit-fixed-math.mjs
npm run coverage:finance
npm run audit:distributions
npm run audit:distributions:deep
node scripts/smoke-all-casebook.mjs
```

Последняя браузерная команда требует локально установленный `playwright-core` и Chromium. В CI обе проверки запускаются автоматически. Отчёт по независимым математическим эталонам сохраняется в `artifacts/fixed-math-audit.json` и прикладывается к сборке GitHub Actions.

### Границы достоверности

Математическое совпадение подтверждает числовую правильность **в рамках исходных допущений**. Оно не подтверждает автоматически достоверность исторических фактов, действующего законодательства, конкретного налогового режима или всех качественных рекомендаций. Для этих утверждений требуется отдельная проверка первоисточников и времени действия правил.
