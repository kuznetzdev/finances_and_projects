# Интеграция проверенного банка задач

Версия приложения: 5.0. Источник: [полный банк задач, редакция 1.1](CASE_BANK_SOURCE.md) от 22.10.2026, 57 задач F01–F19, T01–T17 и V01–V21. Числа, постановки, решения и оговорки источника сохранены без замены «неудобных» ответов выдуманными ставками или фактами.

## Как работает тренировка

В разделе **Задачи → Банк задач** можно выбрать область, найти исходную задачу или получить случайную задачу с защитой от недавних повторов. Слева показано полное условие, справа рабочая тетрадь с шагами. На узких экранах блоки идут друг под другом. Ответы сохраняются локально при переходах.

Задачи делятся на два сценария:

1. **Числовая проверка (21 кейс).** Для отдельных задач из банка авторизованы контрольные ответы в `site/data/case-checkpoints.js`. Числовые поля проверяются с заданной точностью. Неверный ответ не выдаёт ложной отметки о сдаче. Можно раскрыть полное решение.
2. **Самопроверка (36 кейсов).** Когда задача предполагает аргументацию, неоднозначное условие или сложную таблицу, обучающийся пишет ход решения и поэтапно открывает сохранённые решения источника. Отметки «Разобрался» / «Нужно повторить» субъективны; приложение честно не имитирует объективную автоматическую проверку свободного текста.

Кейсы с оговорками подсвечены. Например, F05 нельзя интерпретировать как доказанный дефицит денег, F18 нельзя автоматически прощать долг обанкротившемуся поставщику, T15 нельзя считать вторую цену по НКД без конвенции, V15 нельзя смешивать базы сравнения опциона на отсрочку.

## Дополнительные генераторы

9 новых параметризованных семейств `bank-*` находятся в `site/engine/templates/bank-derived.js`: баланс операций, EBITDA, косвенный ОДДС, амортизация с разными ставками, CAPM, санкции за нарушение ковенанта, амортизируемая облигация, мост EV → Equity и ликвидность после чрезвычайных событий. В отличие от оригиналов банка они пересчитывают **все числовые данные и ответы из одной модели**, сохраняют единицы, условия и допущения. Число полей увеличивается с уровнем сложности.

**Не генерализуем автоматически** исходные недоопределённые сюжеты с произвольными числами. Это отдельный жанр тренировок «найти недостающие сведения».

## Источники и сборка

- `docs/CASE_BANK_SOURCE.md`: исходный предоставленный Markdown, без изменений.
- `scripts/build-bank.py`: статический генератор безопасно санитизированного HTML из исходника.
- `site/data/case-bank.js`: сгенерированный, зафиксированный в Git каталог 57 кейсов.
- `site/data/case-checkpoints.js`: только вручную сверенные с документом числовые контрольные точки.
- `site/engine/casebook.js`: чистая модель фильтров, анти-повторов и проверки числа.
- `site/features/casebook-ui.js`: независимая UI-часть рабочей тетради.
- `tests/casebook.test.js`: регрессионные проверки чисел, структуры и 9 новых генераторов.

Повторная генерация статического каталога:

```bash
python3 -m pip install -r scripts/requirements-bank.txt
python3 scripts/build-bank.py
npm test
```

Содержание задачи не следует редактировать в `case-bank.js`: только в исходнике с повторной независимой вычиткой и аудитом решения.

## UX и доступность

- Настольный размер: условие и тетрадь в двух колонках, кроме узкого рабочего пространства.
- Телефон: условие, затем одна группа ответа; перемещение по шагам без горизонтального скролла страницы.
- Денежные таблицы исходника прокручиваются **внутри блока условия** только если не помещаются; строки сохраняют исходные единицы.
- Все действия доступны кликом/тапом и с клавиатуры; для финансовых чисел можно вводить запятую или точку.
- Процентные ставки, п.п., рубли и миллионы рублей в вопросах подписаны явно.
- Вопросы с несколькими выводами требуют осмысления, а не случайного «угадывания» единственного числа.

## Ограничения

В 36 кейсах проверка ручная. Сохранённая запись самооценки не доказывает правильность рассуждения. Кроме того, автоматическая конвертация многоколонных исходных таблиц допускает внутреннюю горизонтальную прокрутку на узком экране. Юридическая и налоговая актуальность некоторых исходных авторских условий ограничена датой самого банка; действующие ставки для новых генераторов отдельно версионируются.
