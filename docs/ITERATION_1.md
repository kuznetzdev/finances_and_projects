# Итерация 1: амортизация, налоги и денежные потоки

## Объём

Эта итерация расширяет учебное приложение четырьмя параметризованными генераторами, одним комплексным кейсом B13 и восемью новыми понятиями. Исходный банк из 57 кейсов не изменяется.

### Генераторы

| ID | Содержание | Основные допущения |
| --- | --- | --- |
| `tax-depreciation-method-comparison` | Линейная амортизация, сумма чисел лет, уменьшаемый остаток, приведённая стоимость налогового щита | В учебном сценарии все методы разрешены для налогообложения; налогооблагаемой прибыли достаточно, CAPEX одинаков |
| `tax-temporary-differences` | Бухгалтерский и налоговый графики, текущий налог, ОНО, совокупный налоговый расход | IAS 12 в упрощённой модели одного актива, без других временных разниц |
| `tax-payments-schedule` | Начисление налога поквартально, платежи через квартал, долг на конец года | Платёжный лаг специальным образом задан в условии; это не налоговый календарь РФ |
| `tax-loss-carryforward` | Перенос убытка на три периода, ограничения списания, налоговая экономия | Лимит 50% или 100% задан только для учебной задачи, без автоматического признания ОНА |

У каждого генератора фиксируются налоговая политика, числовые промежуточные результаты, разъяснения и `audit` для независимой проверки.

### Банк решений

`B13`: многолетняя модель на 5 лет по амортизации, налоговой базе, ОНО, текущим платежам, CFO и приведённой стоимости налоговой экономии. Есть отдельные числовые контрольные точки.

Файлы: `site/data/advanced-cases.js` и `site/engine/casebook.js`.

### Словарь

Восемь новых понятий: линейный метод, уменьшаемый остаток, сумма чисел лет, временная налоговая разница, постоянная разница, текущий налог к уплате, использование перенесённого убытка и расход по отложенному налогу.

Формулы хранятся в `site/data/glossary-formulas.js`, обозначения используются из текущего каталога. Все новые записи имеют источник, отличие от близкого понятия и границы применимости.

## Проверки и границы применимости

- Генераторы не подменяют учебные допущения действующим налоговым законодательством.
- Величина налогового щита рассчитывается только при возможности использовать соответствующий вычет.
- Временная разница и налог к уплате не смешиваются с денежным потоком.
- При сравнении PV налогового щита важно, возникает экономия в год начисления или позднее.
- Для новой налоговой политики требуется отдельная версия правил; исторические кейсы не перезаписываются.
- Вся база проверяется командой `npm test`. Отдельные инварианты новых генераторов тестируются на 400 детерминированных вариантах каждого типа.

## Проверяемый критерий завершения

Реестр содержит 108 генераторов, 68 кейсов и 216 канонических понятий. Все тесты и браузерные проверки доступных GitHub Actions должны пройти на отдельной ветке до решения о слиянии.
